# resign-life-simulator

裸辞之后：像素人生模拟器。

手机一屏布局、专属像素角色、持续年度故事线、随机事件和结局图鉴。进度保存在本机浏览器。

## 运行

这是纯静态网站，无构建步骤，无 API 密钥和数据库。

本地预览：`python3 -m http.server 8080`，然后打开 `http://localhost:8080/`。

Vercel：Framework Preset 选 Other；Root Directory 为仓库根目录；Build Command 和 Install Command 留空；Output Directory 为 `.`。
